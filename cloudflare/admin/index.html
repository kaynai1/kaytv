▶ KayTV 云后台

概览

影视源、TVBox、公告和云账号都从这里统一管理，三端打开后自动同步。

客户端怎么接

  1. 三端打开「设置 → 云后台」。
  2. 粘贴本页右上角的云后台地址，保存并同步。
  3. 公告和启用的源会立即出现在手机、TV、Windows 上；连不上后台时照常使用内置源。

建议开启

先填 2-3 个稳定影视源并点「检测」；用户注册可以设置成需要审核；公告支持定时上下线。

源体检与告警

定时任务分批检测启用的源，连续失败或有效期临近会在这里生成告警；处理完可手动关闭。

最低版本：低于该版本的三端会弹出强制更新提示并锁定播放，填 0.5.0 表示 0.5.0 以下必须更新。留空则不强制。

安全提示

ADMIN_TOKEN 建议至少 24 位随机字符，只放在 Cloudflare 的 Secrets 里，不要写进仓库。 云账号密码使用 PBKDF2-SHA256 加盐存储，管理后台永远看不到明文。
